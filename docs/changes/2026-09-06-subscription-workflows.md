# 订阅工作流的行为变化

本文记录订阅工作流重构相对 `5b3ff86` 的用户可见行为变化与错误诊断处理。需求依据是订阅链接转换、生成链接状态和配置上传结果三个已确认的改进方向。

## 订阅链接转换

以下变化影响链接导入与重新生成：

| 场景 | 先前行为 | 更新后的行为 |
| --- | --- | --- |
| 导入失败 | 校验完成前可能改写后端地址和客户端类型 | 解析成功后才应用完整表单，失败时保留原表单和自定义参数 |
| 导入显式 UDP 参数 | 参数值被读取，但重新生成依赖复选框操作记录 | 区分未指定、开启和关闭，进阶模式生成时保留显式 `true` 或 `false` |
| 多行源订阅使用 CRLF 换行 | `\r\n` 被替换为两个 `\|` 分隔符 | 一个 CRLF 换行转换为一个 `\|` 分隔符 |
| 必填项只有空白字符 | 非空字符串可通过表单校验 | 源订阅和客户端类型经过空白检查，纯空白输入校验失败 |
| 自定义参数有名称但值为空 | 生成时忽略该参数 | 保留为 `name=`，使导入的空值参数能够往返保留 |
| 后端地址包含查询参数 | 直接拼接，要求调用方准备好末尾分隔符 | 根据已有查询串和末尾字符选择 `?`、`&` 或不追加分隔符 |
| 查询参数编码 | 使用字符串拼接和 `encodeURIComponent` | 使用 `URLSearchParams`；空格可编码为 `+`，按标准查询串规则解码后的值不变 |

基础模式仍只生成目标客户端、Surge 版本（如有）、源订阅和 `insert`。缺失布尔选项仍沿用原有导入语义，解释为 `false`；UDP 单独保留“未指定”状态。复选框对“未指定”和“关闭”均显示为未勾选。

## 短链接识别与生成结果

短链接展开通过查询参数中的 `target` 判断是否为直接转换链接。路径中含有 `target`，但没有该查询参数的链接，会进行重定向展开；此前仅检测字符串是否包含 `target`，会错误地跳过展开。

每次生成定制订阅都会使旧短链接及其未完成请求的结果失效。过期请求返回的结果或错误均不覆盖当前链接，也不修改新请求的等待状态。Clash 导入优先使用当前长链接对应的短链接，否则使用当前长链接。

修改表单本身不会自动重新生成定制订阅。

## 配置上传与对话框

上传流程统一返回配置链接和复制结果。自动复制返回失败或抛出异常时，上传仍视为成功：远程配置字段获得新链接，对话框保留该链接供手动复制。上传被拒绝或请求失败时，保留已有远程配置。纯空白配置不能提交。

上传和链接解析各自维护等待状态。请求期间禁用对应对话框的输入、确认、取消、遮罩关闭和 Escape 关闭，并在方法入口拒绝重复提交。这避免了重复请求和关闭对话框后仍应用结果的情况。

这项交互调整没有提供请求取消能力，也没有新增超时机制。如果请求长期挂起，对话框会持续等待；用户需要等待请求结束或重新加载页面。这是锁定对话框的限制。

## 错误诊断

短链接展开失败时，页面显示中文错误提示。错误通过 `Error.cause` 保留原始原因，供调用方排查；页面仍只展示外层提示。

此前虽然错误字符串拼接了底层原因，但旧解析流程随后将其替换为通用错误提示，并未将底层原因展示给用户。

## 验证范围

回归测试覆盖 UDP 三态、失败导入的原子性、CRLF 规范化、自定义参数往返、后端查询串拼接、过期短链接结果、重复提交，以及上传和复制结果的组合。网络与剪贴板失败使用可控替身验证，不代表真实远端联调结果。

运行全部回归测试：

```sh
node --test tests/subscription-workflows.test.mjs
```

运行短链接展开和错误原因保留的验证：

```sh
node --test --test-name-pattern='short-link resolution' tests/subscription-workflows.test.mjs
```
